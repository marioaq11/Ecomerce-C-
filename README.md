📦 E-comerce

La clase Product representa un producto en el sistema, almacenando información como nombre, precio, disponibilidad, fecha de creación y un identificador único (Guid).

Incluye un constructor que inicializa automáticamente algunos valores clave al crear el objeto, como la fecha actual y un código único.

Además, proporciona métodos para aplicar descuentos al precio (ApplyDiscount) y obtener una descripción básica del producto (GetDescription), la cual puede ser personalizada en clases derivadas gracias al uso de virtual
